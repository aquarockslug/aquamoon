# wm

Aquamoon's river window manager, forked from
[tinyrwm](https://codeberg.org/river/tinyrwm) and implemented in Lua. The
implementation lives in `wm.lua`; protocol bindings and helpers are in `wm/`.

## Dependencies

System dependencies:
- lua (5.4)
- luarocks
- libwayland
- libxkbcommon

The lua-ecosystem dependencies are handled by luarocks:
`cffi-lua`, `firefly/wau` and `luaposix`.

## Layout

| Path | Purpose |
|:-----|:--------|
| `wm.lua` | window manager implementation |
| `xkbcommon.lua` | keysym helper |
| `protocol/*.xml` | river protocol descriptions |
| `protocol/*.lua` | generated by `wau-scanner` |

## Running

In the aquamoon checkout, `../bin/wm` launches `wm.lua` with the Lua 5.4 module
paths it needs. `~/.config/river/init` execs that launcher, so a normal `river`
start uses the working tree directly:

```sh
river
```

Make sure libxkbcommon.so and libwayland-client.so are present in
`LD_LIBRARY_PATH` (and `river` and `foot` in your `PATH`).

## Optional install

The rockspec is kept for installing outside the checkout:

```sh
eval $(luarocks --path bin)
luarocks --local make
```
